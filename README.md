This project implements a wearable gas‑detection device for industrial and mine safety using an ESP32 microcontroller, environmental sensors (temperature, humidity, and gas), and ESP‑NOW for low‑latency, router‑free peer‑to‑peer communication. Each wearable node periodically samples sensor data, encodes it as JSON, and transmits it over ESP‑NOW to a local base station or gateway, which can further relay alerts to a cloud dashboard (e.g., Firebase) or trigger on‑site alarms. The design emphasizes low power consumption, simple deployment without Wi‑Fi infrastructure, and real‑time monitoring of hazardous conditions.
